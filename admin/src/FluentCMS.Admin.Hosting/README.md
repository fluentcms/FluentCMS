# FluentCMS.Admin.Hosting

Serves a [FluentCMS](https://github.com/fluentcms/FluentCMS) admin app from an ASP.NET Core host: its `config.json` from the host's configuration, the registration of the admin client and the headers of the admin page. This preview holds no type yet; section 6.1 of the [admin technical specification](https://github.com/fluentcms/FluentCMS/blob/main/docs/planning/admin-technical-spec.md) has the design.
