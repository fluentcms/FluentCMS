# FluentCMS.Admin.RichText

The rich text editor of the [FluentCMS](https://github.com/fluentcms/FluentCMS) admin, which an app loads lazily the first time a form has a rich text field. This preview holds no editor yet; section 4.7 of the [admin technical specification](https://github.com/fluentcms/FluentCMS/blob/main/docs/planning/admin-technical-spec.md) has the design.
