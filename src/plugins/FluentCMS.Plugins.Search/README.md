# FluentCMS.Plugins.Search

Full-text search for [FluentCMS](https://github.com/fluentcms/FluentCMS): an index of the fields marked searchable, kept current from the entry events, on PostgreSQL full-text search, SQLite FTS5 or a match on a part of the text on SQL Server, behind the `q=` parameter of the content lists. Section 5.7 of the [backend technical specification](https://github.com/fluentcms/FluentCMS/blob/main/docs/planning/backend-technical-spec.md) has the design.
