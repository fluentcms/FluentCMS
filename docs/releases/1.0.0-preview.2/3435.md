## Additions

- The reference host and its image read the Data Protection key ring with previous certificates as well, from `FluentCms:DataProtection:PreviousCertificates` (`0:Path` and `0:Password`, and so on), which only unprotect the keys they protected and never protect a new one, so the key ring certificate can be replaced without losing the older keys. An entry that cannot be read or holds no RSA private key, one with a password and no `Path`, and previous certificates without a current one stop the host with `FCMS3155`; an entry whose members are all empty is absent. Outside Development the startup report lists `data-protection-previous-certificates` with their thumbprints. `docs/host-configuration.md` and `docs/docker.md` give the steps of a replacement and what to do instead when the old certificate's private key may have leaked (#3435).
