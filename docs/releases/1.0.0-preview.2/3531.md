## Changes that break code built before this preview

- A host that replaces `Events` or sets `EventsType` on the `OpenIdConnectOptions` of a provider of `FluentCms:Sso` in a `PostConfigure` registered after `AddFluentCms` does not start, with `FCMS3070` naming the provider, since it would drop the check of the provider's remote sign-out. A delegate a host sets on `options.Events` there, as `OnRemoteSignOut` or `OnTokenValidated`, now runs after FluentCMS's part of the event instead of replacing it (#3531).

## Additions

- A sign-out whose `user.sessions_ended` or `member.sessions_ended` row cannot be written still finishes: the logout endpoint, the member logout page and a provider's remote sign-out delete the cookie and answer as they do otherwise, where they answered 500 and left the cookie in the browser with its tokens revoked. A sign-in over another one, or with the second factor, likewise goes on. The failure is logged as an error with event 9012 (`SessionEndNotRecorded`), with the pool, the id and the reason, and no row is written (#3531).
- `member.sessions_ended` with the reasons `password_changed`, `deactivated`, `login_removed` and `deleted` is written only when the member had a live session, a valid authorization or a valid token that has not expired. Every authorization and token of the member is revoked as before (#3531).
