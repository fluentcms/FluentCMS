## Additions

- Every answer of `/api/management/v1/api-keys` that carries a key, the list, `GET /api-keys/{id}`, the create, the rotation, the expiry and the change of addresses, has `maxOverlapSeconds`: the longest overlap a rotation takes, in whole seconds as a JSON integer, which is `FluentCms:ApiKeys:RotationOverlap` and what a rotation that leaves `overlapSeconds` out gets. A longer one is still refused with `FCMS3026`. A client offers the range before it rotates instead of learning it from the refusal (#3497).
