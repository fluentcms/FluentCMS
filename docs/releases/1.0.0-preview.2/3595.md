## Changes that break code built before this preview

- `GET /me/sites` and `IPermissionChecker.HoldsGrantInAsync` count a grant only when it gives its holder a permission in the site: a content permission, under its row rule if it has one, a permission outside content with no row rule, or, for a grant limited to resources, a permission outside content with no row rule and at least one resource, which `ResourcesAsync` gives a plugin that asks. A grant stored with a row rule beside a permission outside content, a grant of content alone limited to resources and a stored grant with an empty resource list no longer make a site count, so a caller whose only grants in a site are such grants no longer sees the site in `GET /me/sites`, and the MCP plugin no longer serves it the site's guidelines, the instructions of its types or its stored prompts. Such grants gave no permission in the site before either. The signature of `HoldsGrantInAsync` is unchanged (#3595).
