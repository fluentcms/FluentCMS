## Changes that break code built before this preview

- Scheduled publish and unpublish (`content.schedule.publish`, `content.schedule.unpublish`) and the account mail jobs (`members.send_mail`, `users.send_password_reset`) have an attempt timeout of five minutes, whatever `FluentCms:Jobs:AttemptTimeout` says (#3408). Past it the job's token is cancelled and the attempt fails with `FCMS2508` and is retried, and a job that ignores its token is abandoned 30 seconds later and its worker freed. A host's `IEmailSender` that takes longer than that to send is cut off the same way.

## Additions

- `IPluginServiceBuilder.AddJob<TJob, TPayload>(type, attemptTimeout, resumable)` registers a plugin's job as resumable: one that stops on its token at its attempt timeout has succeeded and leaves what is left for its next run, so a long backlog is never dead-lettered for its size. Its default throws `NotSupportedException`, so a builder other than core's builds as before. The retention jobs of the AI Assist and Webhooks plugins are registered so (#3408).
- Before `jobs.retention` removes a dead-lettered job, a pending schedule that still names it, as after a crash before the schedule heard of the job, is failed with the error that its job was dead-lettered and removed, and its entry no longer shows the scheduled time (#3407).
- A database made by `1.0.0-preview.1` lacks the indexes added to the baseline since: `ix_cms_job_status_completed`, `ix_cms_outbox_failed`, `ix_cms_outbox_handler_pending` and, with the webhooks plugin, `ix_cms_webhooks_delivery_queued`. It still starts, and a start or `fluentcms migrate` logs a warning, event id 9306, that names them; a preview does not upgrade a database, so recreate it to get them. A missing unique index of the model is refused with `FCMS1308`, as a missing column is (#3407).
