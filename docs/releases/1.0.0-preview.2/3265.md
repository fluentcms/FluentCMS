## Changes that break code built before this preview

- A write that changes a shared (non-localizable) field, whether a save, a discard of the draft, a version restore or a publish whose hooks change the draft, advances the draft version of every other locale of the entry too, with a version of its own whose message is `Shared fields changed in {locale}.`, so a write or publish of another locale with a version read before it answers 412, and of two writes of two locales that cross, one does (#3265).
- A list with `locale=all` holds every entry the caller may read once, also one with no row in the site's default locale, and is filtered, sorted, paged and counted by the entry's row in the first locale, the default and then the site's order, that has one the caller may read; it was the default locale's rows alone. A search with `locale=all` still searches the first locale the caller may read (#3277).
- `MaxPopulatedEntries` holds for the whole answer of a read: the locales of a `locale=all` read and the locales a read falls back to count together, so such a read that inlines more related entries than the cap is refused with `FCMS2207`, where each locale had a cap of its own before (#3284).
