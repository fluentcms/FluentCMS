## Additions

- The endpoints a surface marks as serving its static files count before authentication in a partition of their own per client address, `FluentCms:RateLimits:StaticFiles:PermitLimit` (15000 a minute), instead of the coarse `PreAuth` limit, so that loading a surface's files from an office behind one address does not use up the allowance of its API calls. Only the endpoint's own mark counts, never the path or the extension of the request: a page, a configuration file, a fallback, also one that answers a path matching no file, and every API and sign-in request count under `PreAuth` as before, and so does a marked endpoint under a group of core. A key sent with such a file is never looked up, as on `/health`. A refusal is the same 429 problem, counted by `fluentcms.rate_limit.refused` under the policy `static-files`. The admin marks the files of its app, and not its `index.html`, `config.json` or client routes, as of #3451 and #3577 (#3452).
