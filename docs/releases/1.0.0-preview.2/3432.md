## Additions

- `GET /api/management/v1/schema` and `GET /schema/types/{type}` answer `previewable` on each type, and `SchemaTypeDescription.Previewable` holds it: true when the site has a template of the settings area `preview` for the type that fits it as the caller sees it, and the caller may mint a preview token of it, with the `management` scope and a draft read. A template that reads a field the caller may not read counts as none, and so does one the schema no longer fits; a component, a block and a description outside an operation are never previewable, and a caller without the `management` scope, such as an MCP client's token on the plugin's schema resources, reads false for every type. A client learns whether a type has a preview page without minting a token (#3432).
