## Changes that break code built before this preview

- An import of settings no longer writes a secret that a package names, so each secret keeps what the site has, and an area whose class requires a secret, by `[JsonRequired]` or `[Required]`, is refused with `FCMS2805` on the key unless the site's own row holds a value for it (#3379).

## Additions

- `fluentcms settings reprotect` protects every stored secret setting again under the current default key of the Data Protection key ring, to run before a ring key or certificate is retired; a row it cannot unprotect is left as it is and named by area and scope, and the command ends with `FCMS3308` (#3364).
