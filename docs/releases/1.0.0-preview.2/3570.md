## Changes that break code built before this preview

- `POST /api/management/v1/api-keys/{id}/rotate` checks `apikeys.manage` and the reach of the key before the overlap it asks for, as `POST /api-keys` checks the permission before the ids it names, so a caller without the permission gets 403, and one who has it 404 for a key out of its reach, whatever `overlapSeconds` it sends. A caller without the permission who asked for an overlap longer than `FluentCms:ApiKeys:RotationOverlap` got 422 (`FCMS3026`), which named the configured seconds (#3570).
