## Changes that break code built before this preview

- `POST /api/management/v1/api-keys/{id}/rotate` checks `apikeys.manage` in the site of the request, and then the reach of the key, before the overlap it asks for, as `POST /api-keys` checks the permission before the ids it names. For any `overlapSeconds` that binds, a caller without the permission gets 403, and one who has it 404 (`FCMS3015`) for a key that does not exist or is out of its reach; a value that does not bind is still refused with `FCMS2108` (422) first, as on every route. With an overlap longer than `FluentCms:ApiKeys:RotationOverlap`, both answered 422 (`FCMS3026`), which named the configured seconds (#3570).
