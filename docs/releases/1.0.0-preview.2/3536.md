## Changes that break code built before this preview

- A publish that another request's write of the same draft overtook, a shared field changed in another locale included, answers 412 (`FCMS3105`) with the stored version and entry, also when that write committed while the publish ran; it could answer 409 `FCMS2405` (`A hook changed the draft being published.`) with no hook involved. `FCMS2405` is still the answer when a hook of the publish changed the draft (#3536).
