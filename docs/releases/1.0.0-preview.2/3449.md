## Changes that break code built before this preview

- `POST /api/management/v1/ai/actions/altText` for an asset alone, with `options.mediaId` and no `type` and `field`, runs only where the site's AI settings turn on `assetAltText`, a new setting that is off by default and in the instance defaults, since such a call sends to the provider an image that no field opted in. A site that used it turns it on in `/settings/ai`, or the instance defaults do for every site that follows them. Off, the call is refused with `FCMS1683` (403), as a field that is not opted in, whatever the asset, and `GET /api/management/v1/ai/fields` answers `assets: false` (#3449).
- `totals.groups` of `GET /api/management/v1/ai/usage` holds at most 100 groups, those that used the most tokens, still ordered by kind, id and action, and `totals.groupsTruncated` is true when the filter matched more. The three totals still count every row. A caller that read every group narrows the filter by `principalId`, `action`, `from` or `to` until `groupsTruncated` is false (#3449).
- `IActivityLog.ActorName` is a new member with no default, which an implementation other than core's must add (#3449).

## Additions

- `IActivityLog.ActorName` gives a name as an activity row's actor and a version's author are stored: a value shaped like a secret masked and the name cut to 128 characters outside a surrogate pair. AI assist writes the `principalName` of a usage row through it, so a name reads the same in `/ai/usage` as in a version's `authorName`. Rows written before were stored as the name was and are not rewritten (#3449).
- `altText` with no `text` and no `documentId` reserves against the daily token budget what it sends, its instructions, the image and `maxOutputTokens`, and no longer the 60,000 tokens of a draft of `MaxInputLength` characters that it does not read, so calls sent beside it are not refused for it (#3449).
