## Changes that break code built before this preview

- An index that fills the `ISearchIndex` slot matches only the fields marked searchable that are not hidden, whatever rows it holds, and `SearchRequest.Fields` set to `null` means a caller who may read every searchable field, not every field or every row. An index other than the search plugin's that matches a hidden field, a field that is not searchable or a field it kept from before, and answered it to a caller who may read every searchable field, must stop, whether its `MatchesByField` is `true` or not (#3376).
