## Changes that break code built before this preview

- An index that fills the `ISearchIndex` slot matches only the searchable fields that are not hidden when `SearchRequest.Fields` is `null` too, which means those fields and not every row it holds, so rows of a hidden field, of a field that is no longer searchable or of one gone from the type never match for any caller. An index other than the search plugin's that indexes such a field and answered them to a caller who may read every field must stop, whether its `MatchesByField` is `true` or not (#3376).
