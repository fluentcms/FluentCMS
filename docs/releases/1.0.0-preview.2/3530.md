## Additions

- The schema readers of PostgreSQL and SQLite list an index whose keys are expressions by its name, as the check behind `FCMS1308` and event 9306 finds the indexes of a model. On PostgreSQL an index of expressions alone, such as a GIN index on `to_tsvector`, was not listed, so a plugin whose model has one would be warned of it at every start, or refused for a unique one; on SQLite such a key failed the read. A key that is an expression is listed with an empty name. SQL Server indexes no expression, and an index on a computed column or with a filter was already listed (#3530).
