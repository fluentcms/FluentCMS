## Changes that break code built before this preview

- A plugin's model in which a table, view, column, key, foreign key, index or check constraint would have a name of more than 63 bytes in UTF-8 on PostgreSQL stops the host in `AddFluentCms` with `FCMS1529`, on every provider, naming the plugin, the name and its length. PostgreSQL keeps the first 63 bytes of a name and drops the rest without a word, so the check behind `FCMS1308` and event 9306, which finds the tables, columns and indexes of the model by name, would not find it and would warn or refuse at every start of a healthy database (#3533).
- That holds for a name the model gives and for one EF derives, such as `IX_...` for an index given none, `PK_...` or `FK_...`, as EF derives it on PostgreSQL: EF cuts a derived name to 63 characters, which is 63 bytes only in ASCII, so a derived name built from a table or column name with other characters can be refused although each name the model gives fits. A column named for one table alone, with entity splitting, TPT or TPC, is measured on that table. Names of what only EF's conventions find, such as a property that no call of the model configures, are not measured (#3533).
