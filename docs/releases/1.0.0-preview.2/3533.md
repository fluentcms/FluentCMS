## Changes that break code built before this preview

- A plugin's model that gives a table, view, column, key, foreign key, index or check constraint a name of more than 63 bytes in UTF-8 stops the host in `AddFluentCms` with `FCMS1529`, on every provider, naming the plugin, the name and its length. PostgreSQL keeps the first 63 bytes of a name and drops the rest without a word, so the check behind `FCMS1308` and event 9306, which finds the tables, columns and indexes of the model by name, would not find it and would warn or refuse at every start of a healthy database. The names EF makes, such as `IX_...` for an index given none, are left as they are, since EF cuts them to the provider's limit itself (#3533).
