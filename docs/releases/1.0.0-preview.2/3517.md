## Changes that break code built before this preview

- `DELETE /api/management/v1/sites/{id}/locales/{code}` refuses a locale that another locale of the site names in its fallbacks, enabled or not, with `FCMS3143` (409) and one error for each such locale at `locales.{code}.fallbacks`; it was removed and left in those chains, so a later change of one of them was refused with `FCMS2312`. Take the locale out of those fallbacks first. A locale whose fallbacks are the implicit chain names none, and a removal changes no chain (#3517).
