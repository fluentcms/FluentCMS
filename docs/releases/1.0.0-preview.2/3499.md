## Additions

- `SettingsAttribute.InstanceOnly` registers a settings area that is read from the instance defaults only, with `ISettings<T>.GetDefaultAsync`, so that a site's own values change nothing: `[Settings("area", InstanceOnly = true)]`. `branding` and the MCP plugin's `mcp` are registered so. Each area of `GET /api/management/v1/settings` says it as `instanceOnly`, for a plugin's area as for core's, so that a client sends such an area to `/settings/{area}/defaults` without knowing it by name. The routes of the area answer as before (#3499).
