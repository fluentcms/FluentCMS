## Additions

- The consent page names a redirect URI of any scheme other than `https` and `http` by its scheme, so `myapp://callback/x` is `myapp:`. It showed the authority of such a URI, `callback`, as if it were a web host (#3442).
- A configured client whose redirect URI or post-logout redirect URI changed only in the case of its host is written at the next start, since the authorize and logout endpoints compare a URI with the stored one as strings. The stored URI kept its old spelling, so a client that sent the URI as configured was refused. Its users' consents stay, since the URI names the same place (#3442).
