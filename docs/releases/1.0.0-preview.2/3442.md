## Changes that break code built before this preview

- A configured client whose redirect URI or post-logout redirect URI changed only in the case of its host is written as configured at the next start, since the authorize and logout endpoints compare a URI with the stored one as strings. From that start on, a client that still sends the old spelling of the host is refused, and one that sends the URI as configured is accepted; the stored URI kept the old spelling, so it was the other way round. Its users' consents stay, since the URI names the same place (#3442).

## Additions

- The consent page names a redirect URI of any scheme other than `https` and `http` by its scheme, so `myapp://callback/x` is `myapp:`. It showed the authority of such a URI, `callback`, as if it were a web host (#3442).
