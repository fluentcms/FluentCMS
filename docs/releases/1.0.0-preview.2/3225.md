## Changes that break code built before this preview

- A change of API keys made by a key, and sending or revoking an invitation by any caller, check the caller again in the transaction of the write: grants cut, or a calling key revoked, expired, rotated without overlap, past the overlap of the secret it presented or no longer allowed from the request's address, after the checks before it, refuse the change with 403 and write and mail nothing (#3481, #3483).
- A host that sets `Events` or `EventsType` on the `OpenIdConnectOptions` of a provider of `FluentCms:Sso` keeps FluentCMS's check of the remote sign-out and of the token's subject and session: FluentCMS's `OnTokenValidated`, `OnRemoteFailure` and `OnRemoteSignOut` run first, then the host's, and an `EventsType` is resolved once a request as the handler would (#3225).

## Additions

- Every end of a session writes an activity row, `user.sessions_ended` for an admin user and `member.sessions_ended` for a member, with the reason and the actor: a sign-out, a session ended by its owner or an administrator, a password change or reset, a deactivation, a removed login, another change of the user's security stamp, a deleted member, another sign-in over the same browser, a sign-in with the second factor and a provider's remote sign-out. A row names a session ended by its id and never carries a token. The SDK has the new events `UserSessionsEndedEvent` and `MemberSessionsEndedEvent` and the names of their reasons, `SessionEndReasons` (#3207).
