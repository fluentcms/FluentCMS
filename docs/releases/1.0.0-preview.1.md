The first public preview of the FluentCMS backend, a headless CMS for .NET. Every package is on nuget.org as `1.0.0-preview.1`, and the image of the reference host is `ghcr.io/fluentcms/fluentcms:1.0.0-preview.1`, for `linux/amd64` and `linux/arm64`. The preview is there so that the contract is used before 1.0.0 freezes it.

## In this preview

- **The backend.** `FluentCMS.Core`, the engine with the Delivery and Management APIs, the authorization server and its hosted pages; the contract packages `FluentCMS.Sdk` and `FluentCMS.Plugins.Abstractions`; the data providers `FluentCMS.Data.Sqlite`, `FluentCMS.Data.PostgreSql` and `FluentCMS.Data.SqlServer`; and the reference host as an image.
- **The first-party plugins.** Media (with S3 and Azure Blob storage), webhooks, GraphQL, MCP, AI assist, multi-site and search.
- **The tooling.** The `fluentcms` tool (`FluentCMS.Cli`), the templates `fluentcms` and `fluentcms-plugin` (`FluentCMS.Templates`), the source generator, the analyzers and the test host (`FluentCMS.Testing`).
- **Two minimal clients.** `FluentCMS.Client` for C#, and `@fluentcms/client` for TypeScript, which is attached to this release as `fluentcms-client-1.0.0-preview.1.tgz` while it is not on npm.

The admin, the documentation site and the starters are not part of this preview. The [README](https://github.com/fluentcms/FluentCMS/blob/v1.0.0-preview.1/README.md) shows how to start with `dotnet new fluentcms` or with the image.

## Limits

- **The contract can break between previews.** `FluentCMS.Sdk` and `FluentCMS.Plugins.Abstractions` follow semantic versioning from 1.0.0. Until then a preview may change or remove a public member, and its notes name each such change.
- **A preview makes no promise to upgrade a database.** Each migration stream, the system's and each plugin's, starts with one baseline migration for each provider (#3052). A later preview may need a new database. A development database made by the migrations from before the baseline is refused at start and by `fluentcms migrate`, with a message that says to recreate it.
- **Not verified against a real service.** CI calls no provider. Member sign-in with Apple and AI assist on Azure OpenAI have not been run against the real service, and are verified before 1.0.0. Nor, at the time of this preview, have:
  - member sign-in against Google, Entra ID (for the Microsoft handler and generic OIDC) and GitHub (#3007);
  - AI assist against a paid OpenAI-compatible endpoint and a local Ollama (#3008).
- **Search on SQL Server matches a part of the text.** The search plugin uses full-text search on PostgreSQL and FTS5 on SQLite. On SQL Server it matches each word as a part of the text, without a full-text catalogue, so it reads every indexed row of the type, locale and state, and `otnet` finds "dotnet" there only (#3049). No provider ranks by relevance or stems the words of a language.
- **AI assist calls OpenAI-compatible endpoints only.** Its providers are `openAi`, `azureOpenAi` and `openAiCompatible`. Ollama is reached through its `/v1` endpoint without a key, and any other client comes through the `IAiClientFactory` slot (#3048). Settings that name `anthropic` or `ollama` are refused with what to use instead, and a configuration section `FluentCms:Ai:Anthropic` or `FluentCms:Ai:Ollama` stops the host.

## Changes that break code built before this preview

A plugin or a host built on the repository before this preview needs these changes:

- Six interface members of `FluentCMS.Sdk` take as required the parameters they had as optional, other than the cancellation token (#3051): `IActivityQuery.QueryAsync(filter, page)`, `IContentSurface.ReadableFieldsAsync(type, locale)`, `IMediaResolver.ResolveAsync(ids, locale)`, `IMediaService.DeleteAsync(id, force)`, `ITypeBuilder.PublishPolicy(unpublishedReferences, maxVersions, trashRetentionDays)` and `ITransferImport.Report(section, id, outcome, code, message)`, which keeps `Report(section, id, outcome)` as a default member.
- A plugin's field type whose name is not an ASCII letter followed by ASCII letters, digits, `.`, `-` or `_` stops the host at start with `FCMS1528` (#3051).
- `Principal.IsInGroup` throws `InvalidOperationException` outside a row rule, where it answered false (#3004).
- `ISettings<T>.ResolveAsync(SiteId, CancellationToken)` is a new member with no default implementation, so a class that implements `ISettings<T>` must add it (#3005).
- `IDataProvider.ContainsIgnoringCase` is a new member of the `IDataProvider` of `FluentCMS.Core`, with no default, so a data provider built outside the repository must add it (#3012). `IDataProvider` is not part of the two contract packages.

## Security fixes

The review of the code of M4 and M6 (#3047) found three High and three Medium findings, each fixed in this preview:

- An import needs the instance grant for a global type, whatever its package declares (#3062).
- The media files of an import are held to the rules of an upload (#3063).
- `generate csharp` and `generate typescript` keep the field type of a schema snapshot out of the code they write (#3064).
- An import package is bounded in the memory and the storage it can take (#3065).
- A GraphQL mutation whose selection populates too deep is refused before it writes (#3066).
- The `fluentcms` tool checks that an instance answered with a package, a snapshot or a document before it writes the answer (#3067).
