The first public preview of the FluentCMS backend, a headless CMS for .NET. Every package is on nuget.org as `1.0.0-preview.1`, and the image of the reference host is `ghcr.io/fluentcms/fluentcms:1.0.0-preview.1`, for `linux/amd64` and `linux/arm64`. The preview is there so that the contract is used before 1.0.0 freezes it.

## In this preview

- **The backend.** `FluentCMS.Core`, the engine with the Delivery and Management APIs, the authorization server and its hosted pages; the contract packages `FluentCMS.Sdk` and `FluentCMS.Plugins.Abstractions`; the data providers `FluentCMS.Data.Sqlite`, `FluentCMS.Data.PostgreSql` and `FluentCMS.Data.SqlServer`; and the reference host as an image.
- **The first-party plugins.** Media (with S3 and Azure Blob storage), webhooks, GraphQL, MCP, AI assist, multi-site and search.
- **The tooling.** The `fluentcms` tool (`FluentCMS.Cli`), the templates `fluentcms` and `fluentcms-plugin` (`FluentCMS.Templates`), the source generator, the analyzers and the test host (`FluentCMS.Testing`).
- **Two minimal clients.** `FluentCMS.Client` for C#, and `@fluentcms/client` for TypeScript, which is on npm as `@fluentcms/client@1.0.0-preview.1` under the dist-tag `next`.

The admin, the documentation site and the starters are not part of this preview. The [README](https://github.com/fluentcms/FluentCMS/blob/v1.0.0-preview.1/README.md) shows how to start with `dotnet new fluentcms` or with the image.

## Limits

- **The contract can break between previews.** `FluentCMS.Sdk` and `FluentCMS.Plugins.Abstractions` follow semantic versioning from 1.0.0. Until then a preview may change or remove a public member, and its notes name each such change.
- **A preview makes no promise to upgrade a database.** Each migration stream, the system's and each first-party plugin's, starts with one migration, `Initial`, for each provider (#3052), and a database made by the migrations before it is refused with `FCMS1307` (below). A later preview may need a new database.
- **Not verified against a real service.** CI calls no provider. Member sign-in with Apple and AI assist on Azure OpenAI have not been run against the real service, and are verified before 1.0.0. Member sign-in was run on 15 Nov 2026 against Google, Microsoft through Entra ID, GitHub, and generic OIDC against Entra ID, and the host decided each sign-in as specified ([record](https://github.com/fluentcms/FluentCMS/blob/v1.0.0-preview.1/docs/member-sign-in-verification.md), #3007). No sign-in through generic OIDC completed, since both accounts of the run were refused as specified; that and what else the run left open are in #3158 to #3160. AI assist was run against a paid OpenAI-compatible endpoint, OpenRouter, and against a local Ollama, and every step of the walk-through passed on both ([record](https://github.com/fluentcms/FluentCMS/blob/v1.0.0-preview.1/docs/ai-assist-verification.md), #3008).
- **Search on SQL Server matches a part of the text.** The search plugin uses full-text search on PostgreSQL and FTS5 on SQLite. On SQL Server it matches each word as a part of the text, without a full-text catalogue, so it reads every indexed row of the type, locale and state, and `otnet` finds "dotnet" there only (#3049). No provider ranks by relevance or stems the words of a language.
- **AI assist calls OpenAI-compatible endpoints only.** Its providers are `openAi`, `azureOpenAi` and `openAiCompatible`. Ollama is reached through its `/v1` endpoint without a key, and any other client comes through the `IAiClientFactory` slot (#3048). Ollama's `/v1` endpoint reads the older `max_tokens` and not `max_completion_tokens`, which the plugin sends, so an answer is capped at `maxOutputTokens` there only with the site setting `legacyMaxTokens`, which is off by default (#3008). Settings that name `anthropic` or `ollama` are refused with what to use instead, and a configuration section `FluentCms:Ai:Anthropic` or `FluentCms:Ai:Ollama` stops the host.
- **Known bugs in sign-in and sessions.** Four are open, and none of them lets a caller in. An admin user's password change ends the sign-in cookie, the authorization codes and the refresh tokens, but the access tokens already issued work until they expire, one hour by default; a member's password change revokes them (#3202). Another site can end a user's sign-in on the hosted pages with one link, through `prompt=login` or `max_age` at the authorize endpoint (#3203), or, for a user who signed in through an SSO provider, through that provider's remote sign-out path (#3204); each ends the cookie alone. The absolute session lifetime of a code flow counts from its authorize request and not from the sign-in it rode on, so tokens can live up to twice `AbsoluteSessionLifetime` after the sign-in (#3205).
- **Known bugs in operations.** Three are open. On SQLite with several processes on one file, a process that waits for a lock can take it from a holder that is still working, when the holder's lease ran out inside a long write transaction and other processes keep writing; a `fluentcms schema apply` that loses its lock this way says so and is finished by a second run (#3186). On SQL Server a `fluentcms migrate` or a host start that waits for another process's migrations for longer than the command timeout, 30 seconds by default, fails with `Execution Timeout Expired`, which does not name the lock; a second run works (#3192). On Windows a host that loads its signing and key-ring certificates from PFX files leaves their private key files in the user's key folder, `%APPDATA%\Microsoft\Crypto\Keys`, when the process is killed or exits without disposing them (#3212).

## Changes that break code built before this preview

A plugin or a host built on the repository before this preview needs these changes:

- Six interface members of `FluentCMS.Sdk` changed so that no caller compiles a default in (#3051). `IActivityQuery.QueryAsync(filter, page)`, `IContentSurface.ReadableFieldsAsync(type, locale)`, `IMediaResolver.ResolveAsync(ids, locale)` and `IMediaService.DeleteAsync(id, force)` take as required the parameters they had as optional, other than the cancellation token. `ITypeBuilder.PublishPolicy(PublishPolicyOptions)` takes one options record in place of its three parameters, and `PublishPolicyAttribute.DefaultMaxVersions` and `DefaultTrashRetentionDays` are static properties, no longer constants. `ITransferImport.Report(section, id, outcome, code, message)` takes all five, and `Report(section, id, outcome)` stays as a default member.
- A plugin's field type whose name is not an ASCII letter followed by ASCII letters, digits, `.`, `-` or `_` stops the host at start with `FCMS1528` (#3051).
- `scheduledPublishAt`, `scheduledUnpublishAt`, `deletedAt` and `deletedBy` are reserved field names, so a content type with a field of one of these names, which loaded before, is refused with `FCMS1206`, and the analyzers report it with `FCMS0020` (#3094).
- `Principal.IsInGroup` throws `InvalidOperationException` outside a row rule, where it answered false (#3004).
- `ISettings<T>.ResolveAsync(SiteId, CancellationToken)` is a new member with no default implementation, so a class that implements `ISettings<T>` must add it (#3005).
- `IPermissionChecker.CanManageAsync` (#3112) and `IPermissionChecker.HoldsGrantInAsync` (#3070) are new members with no default implementation, so a host that replaced the permission checker, or a fake of it in tests, must add them.
- `IMcpClients.RegisterAsync` and `IMcpClients.ChangeRoleAsync` are new members with no default implementation, so a host that replaced `IMcpClients`, or a fake of it in tests, must add them. `McpClientChangeOutcome` has three new values, `NotApproved`, `InvalidRegistration` and `ChangedMeanwhile`, so a `switch` over it that has no default branch must name them (#3102).
- `VersionInfo` has `AuthorKind` and `AuthorName` after `AuthorId`, which changes its constructor and its `Deconstruct` (#3097).
- `AiProvider.Anthropic` and `AiProvider.Ollama` are gone from `FluentCMS.Plugins.AiAssist`, so host code that names them no longer compiles; use `AiProvider.OpenAiCompatible` (#3048).
- `IDataProvider.ContainsIgnoringCase` is a new member of the `IDataProvider` of `FluentCMS.Core`, with no default, so a data provider built outside the repository must add it (#3012). `IDataProvider` is not part of the two contract packages.
- The system stream and the streams of the media, webhooks, MCP, multi-site, AI assist and search plugins start again from one migration, `Initial`, on SQLite, PostgreSQL and SQL Server, and the migrations before it are gone (#3052). A database made by them is refused with `FCMS1307` before anything is applied: at start, whatever `FluentCms:Database:MigrateOnStartup` says, and by `fluentcms migrate`, and `fluentcms doctor` names it among the reasons the host would not start. Recreate the database (on SQLite, delete its file) and apply the migrations again. A host's own content migrations are not checked.
- A change of the model made after that squash went into `Initial` too, since a preview upgrades no database: the table `cms_default_grant` (#3103), the columns `author_kind` and `author_name` of `cms_version` (#3097), the table `cms_user_preference` (#3096) and the column `owns_file` of `cms_media_asset` (#3133). A database made by a build of `Initial` from before one of them lacks that table or column and is refused with `FCMS1308`, at start and by `fluentcms migrate`, with nothing applied; recreate it as above.
- A plugin named `system` or `content` is refused with `FCMS1502`, since those are the names of core's own streams (#3072).
- An export that includes a global type needs `transfer.manage` for the instance, as an import of one does. A caller with the grant in one site gets 403, and exports the site's own types with `"globalTypes": false`, `types` or `--types` (#3069).
- `fluentcms restore` refuses a backup of another schema or of other migrations unless `--allow-schema-mismatch` is given (`FCMS3249`), and checks the archived database before it replaces the current one (#3068).
- `fluentcms generate` refuses generated files whose names differ only in case (`FCMS3380`), and neither removes nor overwrites a C# file of another namespace in the output folder (`FCMS3381`). It takes the class name of a type ignoring case, so the second of two types whose names differ in case alone is refused with `FCMS3376` (#3070).
- An import refuses, before it writes anything, a package whose manifest names no site or no locales or that holds two files of one name (`FCMS3200`), and one with a content file of a type the instance does not have (`FCMS3202`). A line without an id or a locale code, or with a version number outside 1 to 1,000,000,000, is an item error (`FCMS3212`), and so is a line with a locale the site does not allow when `missingLocales` is `refuse` (`FCMS3203`) (#3069).
- For a host without content migrations, whose types come from a schema file or a sample, `fluentcms migrate` and a start no longer record the schema history; `fluentcms schema apply` records it, and schema sync does when the change loses nothing, so `schema apply` still refuses a removed type or a renamed field whose values would be lost unless `--allow-destructive` is given (#3072).

These members were added and break nothing:

- `OperationContext.IsDelivery`, true for an operation of the Delivery API, and `ResolvedReference.CacheTags`, the cache tags of what a reference resolver resolved, empty by default, which core adds to the Delivery answer (#3109).
- `Permission.DefaultRoles` and `BuiltInRole`, with which a plugin names the built-in roles that get a permission by default (#3103).
- `ContentTypeAccess.Conditional`, the operations that a row rule or the locales of a grant may still refuse for a single entry, empty by default (#3096).
- `PluginAppBuilderExtensions.Takes<T>` in `FluentCMS.Plugins.Abstractions`, with which a plugin's route declares in the OpenAPI document the body it reads by itself (#3104).
- `McpClientRegistration`, `McpClientChange.Error` and `McpClientRoleChangedEvent` of the MCP plugin, for the registration and the change of role of a client (#3102).
- `DisplayName` and `TitleField` on `CollectionAttribute` and `SingletonAttribute`, where `TitleField` takes the property name (`nameof(Headline)`), `ITypeBuilder.DisplayName(string)` and `ITypeBuilder.TitleField(string)` on the builder that core implements, and `displayName` and `titleField` in `schema.json`. They give a collection or a singleton a name for people and the field that labels its entries, which `SchemaType.DisplayName`, `SchemaType.TitleField`, `SchemaTypeDescription.DisplayName` and `SchemaTypeDescription.TitleField` carry, null when not set, and `GET /schema` shows. A title field that is not a single visible text field of its type is refused with `FCMS1220`. `generate csharp` sets the new `FluentCMS.Client.ContentTypeAttribute.DisplayName` and `TitleField`, and `generate typescript` writes `contentTypeLabels` (#3150).

## The Management API for an admin

The audit of the Management API against the rows of the admin (#3050) named what an admin could not learn or do, and this preview adds it:

- **The caller's access.** `GET /me/access` gives, for the site of the request, the permissions the caller holds there and for the instance, and for each content type it may read what it may do and which fields it may set and change. `GET /me/sites` gives the locales of each site, and `GET` and `PUT /me/preferences` keep a user's culture, time zone and formats (#3096).
- **Version authors.** Each item of `GET /content/{type}/{id}/versions` names its author's kind and the name it had at the time, as `authorKind` and `authorName` (#3097).
- **Settings.** `GET /settings` lists the settings areas the caller may manage, with the plugin that registers each. `DELETE /settings/{area}` and `DELETE /settings/{area}/defaults` reset an area, taking `If-Match` as a write does, so a site inherits the instance defaults, secrets included, again (#3098).
- **Preview URLs.** Each content type can have a preview URL template in the new `preview` settings area, per site with instance defaults. The answer of a preview token carries `url`, the draft page with the token, and `publishedUrl`, the published page of the same locale, or null where there is no template or that locale was never published. A template that is not valid is refused with `FCMS3031` or `FCMS3032` (#3099).
- **Media URLs.** `GET /media` and `GET /media/{id}` carry signed `urls` for each asset: the original and, for an image, a thumbnail fitted inside 320 by 320 pixels, as WebP where the image processor encodes it, in a site without presets too. A replace gives an asset new URLs, and a private asset gets short-lived ones (#3100).
- **AI fields.** A caller with `ai.use` reads `GET /ai/fields` to see whether AI assist is on for the site and which fields it may run AI actions on, without reading the AI settings (#3101).
- **MCP clients.** An administrator registers an MCP client for an agent that does not register itself (`POST /mcp/clients`) and changes the role of an approved client (`PUT /mcp/clients/{id}/role`). A change of role ends the client's tokens and its users' consents, so users consent again and the next token carries the new role (#3102).
- **Default grants of plugins.** The built-in Editor and Author roles get `media.read` and `media.upload` of the media plugin, Editor `media.update` too, and both `ai.use` of AI assist, the first time those plugins start on an instance. Each default is given once, so a grant that an operator removes stays removed (#3103).
- **OpenAPI.** The document describes the request and response bodies of every Delivery and Management route of the first-party plugins, and the `If-Match` header that a settings write or reset requires (#3104).

## Media references on Delivery

A media field read with `populate`, and an image of rich text read with `richText=html`, resolve on the Delivery API to an asset of the site's library that is public and not deleted, with the URLs of the media route, whoever reads (#3109). A private asset never resolves there, for a managing key either. On `/graphql` and `/mcp`, a caller that may not manage, such as the Public role, a Delivery key or a preview token, gets the same, and a managing caller resolves by its folder grants as before (#3112). Where the media plugin is disabled for the site, no reference resolves, on the Management API too. A Delivery answer that shows an asset carries its cache tags, so it is evicted when the asset changes, turns private or is deleted.

## Bugs fixed

- A setting that is not text, such as `maxOutputTokens` of AI assist, is no longer taken for a secret by its name (#3079).
- A logout revokes the authorizations issued in the browser's sign-in, with their refresh and access tokens, where it ended the sign-in cookie alone. The confirmed logout, one with an `id_token_hint` of that session and the member logout page revoke them, and so does another user's sign-in in the same browser. The sign-outs another site can cause with one GET, `prompt=login`, `max_age`, `AbsoluteSessionLifetime` and a second factor the role now requires at the authorize endpoint, and a provider's remote sign-out, end the cookie alone (#3203, #3204, #3205). An identity token carries the session as `sid`, and a logout whose hint lacks the session's `sid`, such as a third-party client's token or one from a sign-in before this preview, is asked to confirm, and a logout without the cookie returns to the client without asking only for an identity token of this server issued to that client. The user's other sessions and a third-party client's consent stay; a client without a consent step that must outlive a browser logout, such as a CLI or a native app, is registered with `RequireConsent` (#3198).
- Restoring, reading and diffing a version written before a field was renamed with `[FormerNames]` keep the field's value, and a former name that another field of the type holds is refused (#3085).
- A media reference read on the Delivery API resolves to its public asset, where it answered null (#3109).
- A media reference read on `/graphql` by a caller that may not manage resolves to its public asset, where it answered null (#3112).
- A host starts on an existing SQLite file in rollback-journal mode, such as one copied from elsewhere or made by another tool, and switches it to WAL mode, where it failed to start (#3116).
- An AI assist call that runs past `requestTimeout` is answered as a timeout (`FCMS1688`, 504), where it could be answered as a failure of the provider (`FCMS1689`, 502) (#3008).
- The cache tag header of a Delivery answer is held to 2 KB. A read whose tags would pass it carries the `type:` tags of the entries it shows in their place, and a read whose tags pass it even so carries only `site:{id}` and is sent as `private`, so no CDN keeps a copy it could not purge (#3113).
- An import that replaces the file of an asset removes the old original and its variants when the instance wrote them, where it left them in storage for good. A storage key that a line of a package named is never deleted, by an import or by a replace (#3133).
- `fluentcms schema apply` leaves the tables of a plugin that the host does not register, and lists them, where it dropped them (#3072).
- The source generator emits the builders of a project with a `[Blocks(null)]` field, or with two builders whose names differ in case alone, where it emitted none (`CS8785`). A host refuses `[Blocks(null)]` with `FCMS1211` and `[Select(null)]` with `FCMS1216`, and the analyzers report them, where the host failed to start with an exception (#3071).
- `fluentcms mcp` reads each message as soon as it arrives, recovers from a session that expired and answers every request once (#3068).
- In Production, the startup report lists `member-mail-limit-per-instance` while an email sender is set up and `IDistributedCache` is the in-memory default: the limit of one member mail of each kind a minute to an address then holds per instance, so register a shared cache where several instances run (#3073).

## Security fixes

The review of the code of M4 and M6 (#3047) found three High and three Medium findings, each fixed in this preview:

- An import needs the instance grant for a global type, whatever its package declares (#3062).
- The media files of an import are held to the rules of an upload (#3063).
- `generate csharp` and `generate typescript` keep the field type of a schema snapshot out of the code they write (#3064).
- An import package is bounded in the memory and the storage it can take (#3065).
- A GraphQL mutation whose selection populates too deep is refused before it writes (#3066).
- The `fluentcms` tool checks that an instance answered with a package, a snapshot or a document before it writes the answer (#3067).

The lower findings of the same review were fixed too:

- **Transfer.** An import takes the site's lock only once its body is in, stops when it loses the lock, refuses a crafted package or line before it writes, and answers a body over `MaxPackageSize` with `FCMS3204` whether or not it declares its length. Media files written by an import take a key of their own (#3069).
- **MCP and GraphQL.** A site's guidelines, type instructions, `initialize` instructions and stored prompts reach only callers that may manage and hold a grant in that site, so a Delivery or Preview key gets none. `media_upload` by URL takes port 443 only, and a failed fetch does not name the upstream status. On `/graphql`, a chunked body over `MaxRequestSize` is 413 with `FCMS3111` (#3070).
- **The `fluentcms` tool.** Every `--url` command warns with `FCMS3363` when it sends the key over plain http to another machine, refuses a key with a space or a control character (`FCMS3316`) and a `--site` of `export` or `import` with one, never repeats the `--token` value in a usage error and reads no `@file` response file. `backup` writes the archive for its owner only on Linux and macOS, and text from an instance is printed with its control characters escaped (#3068).
- **Templates.** The `.dockerignore` of the `fluentcms` template leaves `.env`, `*.pfx`, `*.p12`, `*.key`, `*.local.json` and `secrets.json` out of the build context (#3074).
